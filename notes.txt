4. What is http://127.0.0.1:8000/docs?
   That link opens the automatic API documentation page for your app.
   When you build an app using FastAPI, it automatically creates a web page where you can:
   ✅ See all your API routes
   ✅ Test them directly from the browser
   ✅ Send requests without using Postman
   ✅ See what inputs/outputs are expected
   So /docs = interactive testing page for your backend

5. What is FastAPI? (Simple explanation)
   FastAPI is a tool to build backend servers using Python. 
   FastAPI lets your AI talk to users through the internet
   1️⃣ User sends request
   2️⃣ FastAPI receives it
   3️⃣ FastAPI sends text to AI model
   4️⃣ AI generates answer
   5️⃣ FastAPI sends result back
